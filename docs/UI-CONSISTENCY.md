# 全站 UI 一致性优化（进行中）

目标保持不变：在维持网站原风格的基础上优化所有 UI 界面，追求一致性、易读性，减少冗余信息。

## 已落地

- 保留原蓝色主色、浅色背景、侧栏、Element Plus 与现有图标；没有引入新的 UI 框架。
- 14 个主页面统一页头、账户入口、基础字号、面板圆角、间距和弹窗边界。账户错误和 Key 轮转提示保留，静态“已加载”“已选择”信息不再长期占据页头。
- 桌面和窄屏复用同一份导航、会话与 Agent 列表。窄屏通过 Drawer 导航；恢复图像理解、智能路由兼容入口的定位，并提供功能说明入口。会话选择使用原生按钮；重名会话显示已有更新时间以便区分。
- 聊天空状态、模型标签、路由详情和思考内容减少重复说明；技术详情按需展开。群组只在一处展示真实参与模型数量。
- 聊天页移除手动刷新模型入口，选择框移到输入区“清空”左侧，同排等高。进入聊天、窗口恢复、下拉展开和每 60 秒自动更新；隐藏页面、生成中和离开聊天时不轮询。请求合并并校验账户/后端，成功更新不覆盖执行状态，暂时失败保留已有模型和选择，只显示简短错误。
- 控制台以余额和用量趋势为主，明细、充值记录、计费规则分 Tab。已加载记录分页，不删除或截断源数据；注册时间不再使用大号数字导致折行。
- 管理概览将 9 项指标整理成 5 张卡片，总量和今日数据配对，没有移除指标。
- API 高级章节折叠；完整内容和接口示例保留。已有密钥前缀不再被当成完整 Key 复制；示例里的工作流占位符按字面显示，不再访问不存在的 Vue 变量。
- 功能说明改为真实入口和常见任务，不保留硬编码版本和未经当前实现验证的性能描述。
- 语音标签使用键盘可操作按钮，输入具有名称；界面组件使用中文 locale，兼容旧 radio 值的同时消除弃用写法。
- 页面内容不再嵌套第二个 main 地标。减少运动偏好生效。

## 当前证据

本轮改动前已浏览并保存 14 个主页面截图：Agent、聊天、控制台、API、知识库、管理概览、对战、群组、协同推理、语音、全模态、图像理解、智能路由、功能文档。

改动后的真实页面已复查功能说明、控制台、管理概览、API，以及 390px 的导航与聊天；控制台三个 Tab 已检查，既有充值和计费数据仍可访问。发现并修正了重排时 flex 收缩导致趋势图/文档卡片被裁切的问题。临时截图已按要求清理，本文保留验收结论。

聊天模型操作区已额外检查默认 1083px 窗口与 390px 窄屏；选择框和清空按钮中心纵坐标差为 0，均为 32px 高，没有页面/输入区横向溢出。真实下拉列表保留自动路由和当前已配置聊天模型；轮询、焦点、隐藏/生成中暂停、退出清理及请求隔离由真实方法的隔离回归覆盖。未发送测试消息，未更改模型配置。临时截图与检查输出已清理；正式回归测试保留在 frontend/test/chat-model-refresh.test.cjs。

本轮没有新增真实模型/工具执行，没有改动后端接口、数据库结构和已有模型配置。本文保留历史构建与测试结论；构建成功不代表全部子页面验收完成。
