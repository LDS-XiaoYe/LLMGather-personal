# 百炼模型目录同步

管理后台 → 服务商 → **同步百炼模型**。

1. 选择服务商端点对应的地域，填写该地域的百炼 API Key；专属业务空间可填写空间 ID。输入框下方提供 **前往百炼获取 API Key** 和官方指引链接：登录百炼、切换对应地域、在 API Key 页面创建或复制密钥，再粘贴到弹窗。
2. 点击 **获取同步预览**，逐项勾选要新增、删除的模型。新增默认勾选，删除默认不勾选；可以按变更类型筛选或搜索模型／服务商，表头复选框只选择当前筛选结果。未勾选的变更保持不动。
3. 检查已选数量，点击 **确认同步**。仅保存选中的模型变更、对应服务商的可选调用密钥，以及已保留／已选新增模型的能力标签；刷新运行时和当前页面模型列表。

无需修改 `.env`。默认开启 **记住 Key**，成功获取完整预览后，按当前管理员、地域、业务空间加密保存。下次打开显示“已记住”，输入框留空即可复用；填写新 Key 并勾选记住可替换，失败的目录请求不会覆盖原有 Key。后端重启、浏览器刷新后继续保留。

**忘记 Key** 仅移除此管理员在当前地域／业务空间的同步凭证，不删除服务商调用密钥，也不撤销阿里云侧的 Key。取消记住选项只表示不保存此次新输入；如需删除先前记住的 Key，使用忘记按钮。

记住功能复用项目现有 AES-256-GCM 加密机制，凭证不进入通用系统配置列表，不存入浏览器 localStorage，状态接口仅返回掩码。依赖现有 `CHECKPOINT_ENCRYPTION_KEY`，保持部署加密密钥稳定以便重启后读取，管理员无需新增环境配置。取消同步不修改模型，但已经记住的 Key 保留。

“将此 Key 加入同步服务商的调用密钥”是独立选项，仅在确认模型变更时，为选中服务商添加调用 Key，相同 Key 不重复添加；这部分沿用原有服务商密钥存储机制。

## 数据来源与同步范围

- 使用阿里云官方 [`GET /api/v1/models`](https://help.aliyun.com/zh/model-studio/list-models)，按 `page_no`、`page_size` 获取完整目录。默认北京端点 `https://dashscope.aliyuncs.com/api/v1/models` 已通过当前项目 Key 的真实请求验证。
- 地域与 API Key 必须匹配。北京、新加坡、香港支持默认端点；东京、法兰克福、弗吉尼亚填写业务空间 ID，使用官方专属业务空间域名。服务商的现有端点不会被同步修改。
- 只更新所选地域的现有百炼 OpenAI-compatible 服务商，按照 API 返回的模型作者分组；支持现有 qwen、glm、deepseek、kimi、minimax、xiaomi-mimo、gui 分组，以及 bailian／aliyun／dashscope／alibaba 汇总分组。没有对应服务商的作者不会自动创建新的服务商。
- 新增模型要求官方推理服务供应商为百炼／Model Studio，支持 TG、Reasoning 或 VU，输出模态包含 Text，并排除 Realtime。外部供应商、Embedding、图片生成、音视频生成等不会加入聊天模型列表。仍在目录中的现有非聊天模型保留。
- 模型能力标签根据 API 的能力和输入模态补充 language／vision，不覆盖自定义标签。官方上下文长度显示在变更详情中。
- 官方明确下线的模型列为删除候选；计划下线但日期未到的模型保留。**目录中缺失不等同于全球下架**：默认开启“列出本地域官方目录中已不存在的旧模型，供选择删除”，也可取消该选项仅列出明确下线模型。所有删除都需勾选后确认。
- Gemini、小米等非百炼端点，以及其他地域／业务空间的服务商保持不变。
- 现有计费、分层、页面白名单、路由和历史会话不修改；新模型沿用现有未分层模型的默认计费规则，不将上游价格自动覆盖为站内价格。

## 保存与失败处理

同步预览不修改模型列表，有效期 10 分钟，绑定当前管理员；勾选记住 Key 时，在成功读取完整目录后单独保存同步凭证。确认模型变更时提交服务商 ID、模型 ID 和变更类型的选择项；服务端逐项核对预览候选，拒绝空选择、重复或伪造项，不接受客户端直接覆盖模型列表。读取失败、空目录、分页缺失／重复／总量变化都中止同步，不删除现有模型，也不覆盖已记住的 Key。

确认时锁定服务商配置，核对完整配置快照。模型列表、可选密钥和能力标签使用同一 MySQL 事务；其他管理员修改配置后，旧预览会失效，需重新获取。运行时刷新失败会明确提示“已保存”，不会把已提交的数据报告为保存失败。

当前预览存于单个 NestJS 进程内。后端重启后重新获取预览；多实例部署需会话亲和或共享预览存储，当前实现未引入跨实例任务缓存。
